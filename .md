src/
├── assets/ # Static files (images, global CSS, icons)
├── context/ # Global state management (React Context, Redux, or Zustand)
├── features/ # The heart of your app: grouped by domain/feature
├── hooks/ # Custom, reusable React hooks (e.g., useLocalStorage)
├── pages/ # Route-level components (e.g., Home.jsx, Dashboard.jsx)
├── services/ # API calls and backend configuration (Node/Express fetchers)
├── ui/ # Generic, reusable "dumb" components (Buttons, Inputs, Modals)
├── utils/ # Pure JavaScript helper functions (formatting dates, math)
├── App.jsx # Main application layout and React Router setup
└── main.jsx # The React entry point
